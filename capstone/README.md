# Sprint Items API — the capstone app

A small FastAPI service used through the whole DevOps sprint: containerized on Day 6, then Compose, CI, ECR and Kubernetes.

## Endpoints
| Method | Path | Returns |
|---|---|---|
| GET | `/health` | `{"status": "ok"}` — used by health checks |
| GET | `/items` | All items |
| GET | `/items/{id}` | One item, or `404` |
| POST | `/items` | Creates an item from `{"name": "...", "price": 1.0}` → `201` |
| GET | `/docs` | Interactive API docs (generated by FastAPI) |

Data is kept **in memory**: it resets when the container restarts.

## Run with Docker
```bash
docker build -t capstone:0.1 .
docker run -d --name capstone -p 8088:8000 capstone:0.1
curl localhost:8088/health
docker rm -f capstone
docker run --rm -v "$PWD":/src -w /src python:3.12-slim \
  sh -c "pip install -q --root-user-action=ignore -r requirements-dev.txt && pytest -v -p no:cacheprovider"
